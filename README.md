Origins Clay

A Java MVC web application for managing clay products for our Advance Programming Coursework.

Project Structure

- Controllers – src/main/java/com/originsclay/controller/
- Services – src/main/java/com/originsclay/service/
- DAOs – src/main/java/com/originsclay/dao/
- Views – src/main/webapp/WEB-INF/views/pages/
- Database – database/Origins_Clay.sql

Database Setup

1. Create a MySQL database 
2. Import the dump: origins_clay < database/Origins_Clay.sql
